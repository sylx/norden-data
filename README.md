# norden-data

nordencult のゲームデータのエディタ。拠点データ・勢力データ・騎士データ・施設データ・技術データ・セリフを編集し、ゲーム本体（nordencult）の `src/` に書き出す。React + TypeScript + Vite。
読み書きは開発サーバーの Vite プラグイン（[server/dataPlugin.ts](server/dataPlugin.ts)）が行うので、`npm run dev` で使う（ビルドはしない）。

nordencult のサブモジュール（`nordencult/norden-data`）として置き、親ディレクトリをゲーム本体として読み書きする。
別の場所に置くときは `NORDEN_ROOT=/path/to/nordencult npm run dev`。

```sh
npm install
npm run dev        # http://localhost:5180/
npm run typecheck
```

## 拠点データ（`#cities`）

左で拠点を選んで人口・商業・生産・初期の所属などを入力し、「保存」でゲームの `src/data/cityData.json` に直接書く。
右の地図（`norden-strategy` の拠点の位置 `PLACES` と街道 `ROAD_LINKS` から描く簡易地図）の拠点をクリックしても選べる。
点の色は所属、大きさは人口。地図の右下は勢力ごとの拠点数・人口・商業・生産・兵数の合計。

- 「生産」は以前の「軍事」（`military` → `production`）。ゲームでは 1 ターンに募兵できる上限が 生産 × 5
- 人口の下に Tier と施設のスロット数を出す（ゲームの `src/game/economy/balance.ts` の閾値）
- 「初期の状態」の備蓄・兵数・練度は省略できる。省略中は既定値（備蓄 = 生産 × 2、兵数 = 生産 × 5、練度 = 70）を薄く出し、動かすとその値を持つ。「既定に戻す」で省略に戻す
- 初期の施設は施設データ（`#buildings`）の元データから選ぶ（ゲームに書き出していない施設も出る）。必要なタグが合わない施設、スロットより多い施設、アップグレード元と重ねた施設、遺物の要る施設も選べるが、注記を出す
- 地図の描画（町・大都市の描き分けなど）は `norden-strategy` の `CITY_LIST` を使っていて、ここで変えた人口などは反映されない

## 勢力データ（`#factions`）

左で勢力を選んで名前・当主の呼び名・色・紋章・初期の金を入力し、「保存」でゲームの `src/data/factionData.json` に直接書く。
一覧の上で ID（英小文字・数字・`_`。`mercenary` は傭兵のまとまりに使うので不可）を入れて「追加」。ID は拠点の所属・騎士の勢力から参照されるので、後から変えない。

- 一覧の順が手番の順（プレイヤーの勢力が先）。↑↓ で入れ替える
- 「初期の金」は省略できる。省略中はゲームの `INITIAL_GOLD`（`src/game/economy/balance.ts`）を薄く出す
- 紋章は `norden-strategy` の `src/assets/emblems/` の番号。ほかの勢力が使っている紋章は薄く出す
- 色は地図の軍団などの色。ほかのタブの勢力の色・名前は、保存するとゲームのデータから読み直す
- 拠点か騎士が所属している勢力は削除できない（先に拠点データ・騎士データで所属を変えて保存する）
- 地図の紋章は `norden-strategy` の `src/data/faction.ts`（ID・名前・紋章の写し）を使っていて、ここで変えても反映されない。写しと違うと注記を出すので、揃えてから使う（ゲームの `src/data/faction.test.ts` が比べる）

## 騎士データ（`#characters`）

[nordencult-old の character-editor](https://github.com/sylx/nordencult-old/tree/main/tools/editor) を移したもの。
元データは [characters/characters.json](characters/characters.json)。「保存」はここに書き、「ゲームに書き出す」で保存してからゲームのデータを作る。

| 書き出し先（nordencult） | 内容 |
| --- | --- |
| `src/assets/character-<n>.webp` | 使っているセルだけを ID 順に横 5 人 × 縦 10 人ずつ並べ、半分（512×768）にした画像。50 人ごとに次の 1 枚（`character-0.webp`、`character-1.webp`、…）。WebP は 1 辺 16383px までなので分けている |
| `src/data/characterData.json` | 能力・略歴など。画像の位置は何枚目か（`sheet`）とその上のピクセル |
| `src/data/characterStart.json` | 初期配置（都市・勢力・領主・捕虜） |
| `src/data/characterSprite.json` | 各 1 枚とセルの大きさ（ゲームの `src/data/characterSheets.ts` が使う） |

画像が未設定のキャラクターは書き出さない。

種別はゲームで率いられる兵科を決める（ゲームの `src/data/unitTypes.ts` の `UNIT_TYPES_BY_CHARACTER_TYPE`。歩兵は誰でも率いられる）。
ライフル兵・砲兵・ランツクネヒトは独自のユニット画像（`norden-battle/assets/units/<兵科>.webp`）を持つ兵科で、同じ種別のキャラクターだけが率いる。

### 元画像

元画像（1 枚に 5 人 × 2 行または 3 行、1 人 1024×1536、間に 50px の余白）は大きいのでコミットしない。
[characters/sheets/](characters/sheets/) に置いて「画像を読み直す」を押す。行数は画像の大きさから決める（5×3 の 15 人、5×2 の 10 人のどちらも読める）。
今の騎士の `001.webp`・`002.webp` は [nordencult-old の tools/editor/uploads/](https://github.com/sylx/nordencult-old/tree/main/tools/editor/uploads) にもある。

キャラクターを選び、元画像のセルをクリックして画像にする。顔の範囲は、枠をドラッグで動かし、外をクリックでそこを中心にし、ホイールで大きさを変える。

## 施設データ（`#buildings`）

元データは [buildings/buildings.json](buildings/buildings.json)。「保存」はここに書き、「ゲームに書き出す」で保存してからゲームのデータを作る。
左で施設を選び、名前・説明・必要なタグ・アップグレード元・必要な遺物・必要な物資と金・効果を入力する。
一覧の上で ID（英小文字・数字・`_`）を入れて「追加」。ID は拠点の初期の施設やアップグレード元から参照されるので、後から変えない。
効果の種類と表示はゲームの `src/data/buildings.ts`（`BUILDING_EFFECT_LABELS`・`describeEffect`）。
説明はフレーバーテキストにし、効果は効果として別に出す。ゲームでまだ表せない効果は「その他」（`kind: "etc"`）にテキストで書く（表示されるだけで、効きはしない）。

- 必要なタグ（どれか）を入れると、そのタグのある都市にだけ建てられる（例: 港湾）。空ならどの都市にも建てられる
- アップグレード元（例: 大市場 ← 市場）を選ぶと、その施設が建っている都市で、その上に建てる施設になる。完成すると元の施設と置き換わり、スロットは増えない。アップグレード先が建っている都市では元の施設は建てられない
- 必要な遺物は名前だけ持つ。ゲームに遺物の所持がまだ無いので、遺物の要る施設は今は建てられない
- 必要な技術（技術データの元データから選ぶ）を入れると、勢力がその技術を研究し終えるまで建てられない（建てられる施設にも出ない）
- 効果「研究」は研究施設の研究ポイント（/ターン）で、系統（物理文明・魔法文明）を持つ。勢力が同じ系統の技術を研究しているあいだは割増になる

| 書き出し先（nordencult） | 内容 |
| --- | --- |
| `src/assets/buildings.webp` | 使っているセルだけを一覧の順に横 5 個で並べ、1/4（256×384）にした画像。同じセルを使う施設は 1 つにまとめる |
| `src/data/buildingData.json` | 一覧の順。画像の位置（`sprite`）は `buildings.webp` 上のピクセル |
| `src/data/buildingSprite.json` | `buildings.webp` とセルの大きさ |

画像が未設定の施設も書き出す（ゲームでは頭文字の札になる）。

### 元画像

元画像（1 枚に 5 × 4 の 20 施設、セルはキャラクターと同じ 1024×1536、間に 50px の余白）は大きいのでコミットしない。
[buildings/sources/](buildings/sources/) に置いて「画像を読み直す」を押す。施設を選び、元画像のセルをクリックして画像にする。

## セリフ（`#voiceLines`）

騎士が場面ごとに言うセリフ。ゲームの `src/data/voiceLines.json` を直接読み書きする（「保存」で書く）。
セリフを引く決まりはゲームの [src/data/voiceLines.ts](../src/data/voiceLines.ts)。

- 左で場面（`battle.attack` など）を選ぶ。場面の ID はゲームのコードが引く名前なので、使っているものは変えない。場面は足せる（汎用。戦闘以外の会話にも使う）
- 真ん中は口調（列）× 性格（行）のマトリックス。数字はセルのセリフの数、点はそのセルに当たる騎士がいること
- 右でセルのセリフを 1 行に 1 つ書く。下のプレビューで騎士を選ぶと、その騎士がこの場面で引くセルとセリフが出る

騎士は自分の口調の列から、「性格を問わない」行と自分の性格（最大 4 つ）の行を合わせて引く。「共通」の列は口調が未設定の騎士（と騎士のいない部隊）が同じように引く。
口調のある騎士は共通の列を使わないので、口調の列にその場面のセリフが無ければ何も言わない。
口調ごとの話し方は「性格を問わない」行に書き、性格の行にはその性格らしい言い回しを足していく。

戦闘（norden-battle）の場面は `battle.` で始まる。一斉攻撃の掛け合いは、攻撃する部隊の `battle.exchange_lead` に、加わる味方（2 部隊まで）がそれぞれ `battle.exchange_reply` で応じる。

## 技術データ（`#techs`）

元データは [techs/techs.json](techs/techs.json)。「保存」はここに書き、「ゲームに書き出す」で保存してからゲームのデータを作る（施設データと同じ流れ）。
左で技術を選び、名前・説明・系統（物理文明・魔法文明）・必要な研究ポイント・前提の技術・効果を入力する。下に系統ごとの簡単なツリー（段ごとの列。選んだ技術の前提とその子に色）を出す。
一覧の上で ID（英小文字・数字・`_`）を入れて「追加」すると、選んでいる技術の子（同じ系統、前提にその技術）として足す。ID は前提や施設の必要な技術から参照されるので、後から変えない。

- 前提は全部要る（複数持てる）。前提の無い技術は根で、最初から研究できる。選ぶと前提が循環する技術は選べない。前提の参照切れ・循環があると書き出さない
- 効果は研究し終えた勢力の全都市にかかる。種類と表示はゲームの `src/data/buildings.ts`（施設の効果と同じ。交易路・研究は除く）。ゲームでまだ表せない効果（一斉攻撃・魔法・遺物の修復など）は「その他」にテキストで書く

| 書き出し先（nordencult） | 内容 |
| --- | --- |
| `src/assets/techs.webp` | 使っているセルだけを一覧の順に横 5 個で並べ、1/4（256×384）にした画像 |
| `src/data/techData.json` | 一覧の順。画像の位置（`sprite`）は `techs.webp` 上のピクセル |
| `src/data/techSprite.json` | `techs.webp` とセルの大きさ |

### 元画像

施設と同じ並び（1 枚に 5 × 4 セル、1 セル 1024×1536、間に 50px の余白）。大きいのでコミットしない。[techs/sources/](techs/sources/) に置いて「画像を読み直す」を押し、技術ごとにセルをクリックして選ぶ。
